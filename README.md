# LinguaFilm AI Studio

Build a modern AI-powered video creation and social media management website called LinguaFilm AI Studio.

The long-term goal is to help users create original AI videos, translate videos into different languages, generate subtitles and voice-overs, and schedule publishing to connected social media accounts.

For VERSION 1, build a beautiful responsive frontend dashboard with a professional dark theme, purple and blue accents, modern navigation, and these pages:

1. Dashboard: overview, recent projects, and content statistics.

2. AI Video Creator: prompt input, video style options, and a mock generation workflow.

3. Movie Translator: video upload interface, source language, target language, and subtitle/voice-over options.

4. AI Assistant: professional chat-style interface for video ideas, scripts, captions, and translations.

5. Social Accounts: cards for Facebook, TikTok, Instagram, and YouTube with clearly marked not-connected states.

6. Content Scheduler: calendar and scheduling form for approved video drafts.

7. Media Library: saved video project cards.

8. Settings: profile and preferences.

Include functional navigation and interactive demo forms. Use local mock data and local browser storage where useful. Label demo features clearly. Do NOT claim videos are actually generated, translated, connected, or posted without real integrations. Do not connect paid APIs yet. Avoid copyrighted movie examples; use original sample content.

Create a clean, organized architecture that can later connect to a database, AI generation services, translation services, and official social media publishing APIs. Start by building and previewing this first version.
